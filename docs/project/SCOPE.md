# Projektscope — TattooTime App1

## Problem
Nachfolger/Alternative zu TattooTimeV2 mit modernisiertem Stack (Vite statt CRA), erweitertem Backend und verbesserter Deployment-Strategie.

## Lösung
Moderne Tattoo-Buchungsplattform mit Vite/React Frontend, Firebase Auth/Firestore, Node.js Backend auf Railway und Firebase Hosting.

## In Scope
- Online-Terminbuchung über Kalender-Interface
- Benutzerregistrierung/-login (Firebase Auth)
- Admin-Dashboard für Tätowierer
- Firebase Hosting + Railway Backend-Deployment
- Firestore-Echtzeit-Daten
- E-Mail-Benachrichtigungen
- Vitest Unit-Tests

## Out of Scope
- Zahlungsabwicklung
- Portfolio-/Galerie-Funktion
- Mobile Native App

## Technologie-Stack
| Schicht | Technologie |
|---------|-------------|
| Frontend | React, Vite, Tailwind CSS |
| Auth | Firebase Auth |
| Datenbank | Firestore |
| Backend | Node.js (Railway) |
| Hosting | Firebase Hosting |
| Tests | Vitest, Playwright |
